API Testing Assignment Summary

This assignment focused on testing REST APIs using Postman. I tested GET, POST, and DELETE requests and covered both positive and negative test scenarios. For each test, I captured screenshots showing the request, response body, and HTTP status code.

Test Results
GET – Get All Posts: Retrieved all 100 posts successfully with a 200 OK response.
GET – Get First Post: Retrieved the first post successfully with a 200 OK response.
POST – Create a Post: Created a new post successfully with a 200 OK response.
DELETE – Delete a Post: Successfully deleted the post created during the POST test with a 200 OK response.
Negative Test – Invalid Post: Attempted to retrieve a post that does not exist. The API correctly returned 404 Not Found.
Challenges

One challenge was understanding how API testing can be automated. Writing automation code requires more time and setup compared with executing the same tests manually in Postman.
